โอนเวร — ระบบทำงานยังไง?

📌 โอนเวร (Transfer)

กดที่ชื่อของตัวเองในปฏิทิน → เลือกคนที่ต้องการโอนเวรให้
เวร ย้ายเจ้าของฝั่งเดียว
หลังอนุมัติ เวรจะเปลี่ยนจากคุณไปเป็นของอีกคน

กดที่ "ชื่อของฉัน" เท่านั้น

🔄 แลกเวร (Mutual Swap)

ถ้าต้องการ สลับกัน 2 ฝั่ง
ทั้ง 2 คนต่างคนต่างกดโอนเวรให้กันและกัน
เช่น A โอนเวรให้ B + B โอนเวรให้ A

ต่างคนต่างกดโอน

📌 โอนเวร — ก่อน / หลัง

👩 A (เจ้าของเวร)
เวรดึก จ.
→
👨 B (ผู้รับเวร)
⬇ หลัง B อนุมัติ
👨 B → เวรดึก จ.
✕
👩 A หลุดจากเวร

🔄 แลกเวร — ต่างคนต่างโอน

👩 A
โอน เวรดึก จ. ให้ B
👨 B
โอน เวรเช้า อ. ให้ A
⬇ หลังทั้งคู่อนุมัติกันและกัน
👩 A → เวรเช้า อ.
&
👨 B → เวรดึก จ.
📋
ขั้นตอนการโอนเวร
1
กดที่ชื่อของตัวเองในปฏิทิน

กดได้เฉพาะเวรของตัวเองเท่านั้น (ชื่อจะแสดงเป็นสีม่วงเข้ม)

2
เลือกคนที่ต้องการโอนเวรให้

ค้นหาชื่อเพื่อนร่วมงานที่ตำแหน่งเดียวกัน

3
พิมพ์ข้อความ (ถ้าต้องการ) แล้วกดส่งคำขอ

ระบบจะแจ้งเตือนอีกฝ่ายทันทีผ่าน Push + ในแอป

4
อีกฝ่ายกด ยอมรับ หรือ ปฏิเสธ

ดูได้ที่ 🔔 > แท็บ "แลก/โอนเวร"

✓
ถ้ายอมรับ → เวรเปลี่ยนเจ้าของทันที

ปฏิทินอัปเดตอัตโนมัติ ทั้งสองฝ่ายได้รับแจ้งเตือน

🔔
ตัวอย่างแจ้งเตือนที่จะได้รับ 📩 มีคำขอโอนเวรให้คุณ
⚠️
หมายเหตุ: โอนเวรได้เฉพาะเดือนที่ Admin ประกาศตารางเวรแล้วเท่านั้น ถ้าเดือนยังไม่ประกาศจะเห็นแถบสีแดง 🔒
⏰
ประเภทเวรและช่วงเวลา
ประเภทเวร ช่วงเวลา สีในปฏิทิน
🌄 รุ่งอรุณ 07:00 – 08:30 น. ส้มอ่อน
🌅 เช้า 08:30 – 16:30 น. เขียวมิ้นท์
☀️ บ่าย 16:30 – 00:30 น. ม่วงอ่อน
🌙 ดึก 00:30 – 08:30 น. น้ำเงินอ่อน

แผนกเวรเช้า:

ER MED (D/C, Cont) SURG Chemo SMC โครงการ
💡
เคล็ดลับสำคัญ

🔔 เปิดการแจ้งเตือน

กด 🔔 > แท็บ "จากระบบ" > เปิด toggle Push
จะได้รับแจ้งเตือนเวรล่วงหน้า 18:00 วันก่อน และ 08:00 วันนั้น

👀 ดูเฉพาะเวรของฉัน

กดปุ่ม "เวรของฉัน" ที่มุมบนขวาเพื่อกรองให้เห็นเฉพาะเวรที่ได้รับมอบหมาย

📱 ติดตั้งเป็นแอป

กดเมนู browser > "เพิ่มลงหน้าจอหลัก" เพื่อใช้งานเหมือนแอปจริง + รับ push notification

⚠️ เวรซ้อน

ถ้าคุณมีเวรในช่วงเวลาเดียวกันอยู่แล้ว ระบบจะเตือน แต่ยังส่งคำขอได้ถ้ายืนยัน

🔒 เปลี่ยนรหัสผ่าน

เข้าสู่ระบบครั้งแรกต้องเปลี่ยนรหัสผ่าน หลังจากนั้นเปลี่ยนได้ที่โปรไฟล์

🏷️ ชื่อเวรย่อใน Excel

E=เช้า ER, D=เช้า MED D/C, C=เช้า MED Cont, S=เช้า SURG, ด=ดึก สามารถใช้ / คั่นหลายเวรได้ เช่น E/ด

🛠️
สำหรับ Admin / Sub-Admin
📂
อัปโหลดตารางเวรจาก Excel

เลือกเดือน/ปี → เลือกไฟล์ .xlsx → ระบบจะอ่าน shift code และบันทึกลง DB

📢
ประกาศตารางเวร (Publish)

เลือก role ที่ต้องการประกาศ → กด Deploy → ผู้ใช้จะเห็นตารางเวรและแลกเวรได้

📊
Export ตารางเวร / หลักฐานค่าตอบแทน

เลือก Original User หรือ Current User → เลือก role → ดาวน์โหลด Excel เพื่อพิมพ์ A4

⚙️
จัดการผู้ใช้และวันหยุด

เพิ่ม/ลบ/แก้ไขผู้ใช้ในระบบ, เพิ่มวันหยุดนักขัตฤกษ์ ใน Settings
